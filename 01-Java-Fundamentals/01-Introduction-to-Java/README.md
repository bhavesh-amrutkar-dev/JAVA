- Explain why Java was introduced and its key features.
- Understand platform independence and bytecode.
- Clearly differentiate JVM, JRE and JDK.
- Explain Java compilation and execution.
- Understand the role of the interpreter and JIT compiler.
- Draw and explain JVM architecture.
- Compile Java programs and inspect bytecode.
- Answer Java fundamentals interview questions confidently.

## 3. Quick Revision — Must Remember

| Concept | One-line explanation |
|---|---|
| Java | High-level, class-based, object-oriented language |
| Bytecode | Intermediate instructions generated by the Java compiler |
| WORA | Write Once, Run Anywhere |
| JVM | Executes Java bytecode |
| JRE | Provides the runtime environment |
| JDK | Provides development tools and runtime components |
| javac | Compiles Java source code |
| Interpreter | Executes bytecode instructions |
| JIT | Compiles frequently executed code into native machine code |
| GC | Reclaims memory occupied by unreachable objects |
| JNI | Allows Java to interact with native code |

---

## 4. Important Comparisons

| Comparison | Remember |
|---|---|
| JVM vs JRE vs JDK | Execution engine vs runtime environment vs development kit |
| Compiler vs Interpreter | Translation before execution vs execution of instructions |
| Interpreter vs JIT | Bytecode execution vs runtime native compilation |
| Bytecode vs Machine Code | JVM instructions vs processor instructions |
| Platform Independent vs Portable | Platform-neutral bytecode vs consistent cross-platform behavior |

## 5. Practical Commands

```bash
# Compile
javac Main.java

# Execute
java Main

# Inspect bytecode
javap -c Main

# Inspect class information
javap -verbose Main
```
